# Operations missions 16

Four original questions. Partial SY0-701 1.3 and 4.2. This targeted set is not a weighted mock exam.

[Mission directory](../resources/hands-on-missions.md) · [Contents](../study/contents.md)

Choose one answer per question before opening the key.

## 1. Two inventory rows have the same serial number, but the exercise requires unique serials. What is the best next action?

- A. Delete either row at random.
- B. Confirm physical identity and source records.
- C. Assume one device was stolen.
- D. Assign ownership from the rack color.

## 2. A cable move gives a green link light. Required application checks have not run. Can the change be closed as successful?

- A. Yes, because every application uses the light.
- B. Yes, if the ticket title is correct.
- C. No; verify the required service functions.
- D. No; all cable moves must fail.

## 3. A record says pending disposal. What supports marking it complete?

- A. The device is no longer on the desk.
- B. A new device was ordered.
- C. The spreadsheet row was hidden.
- D. Applicable retention and approved disposition evidence were checked.

## 4. A change fails its required checks and meets the rollback criterion. What should follow?

- A. Restore the known connection and verify required service functions.
- B. Close the ticket because the move happened.
- C. Invent a successful test result.
- D. Make unrelated changes until something works.

<details>
<summary>Answers and explanations</summary>

1. **B.** B resolves the identity conflict with evidence. A destroys data without justification. C invents a cause. D substitutes an irrelevant cue.

2. **C.** C applies the stated requirement. A overstates the light's meaning, B is unrelated, and D invents a universal failure.

3. **D.** D addresses the disposition process. A and B do not show handling of the old device. C only changes the view.

4. **A.** A follows the plan and checks restoration. B ignores the outcome, C falsifies evidence, and D expands scope without a justified plan.

</details>

Review correct guesses as well as errors. State the missed requirement, explain the nearest alternative, and retry with one changed condition. Supporting documentation is linked in the mission exercises.
