# Asset lifecycle practice set 13

Four original single-answer questions. Partial SY0-701 4.2 alignment. This targeted set is not a complete exam simulation.

## Question 1

A device is found, but no accountable owner is recorded. What should happen before approving its disposal?

A. Treat the last user as automatic approval authority
B. Reconcile ownership and handling requirements
C. Remove it from inventory immediately
D. Assume location alone proves approval

## Question 2

A technician deletes visible files before donation. What does that establish?

A. All media is sanitized
B. Every retention requirement was met
C. Visible files were deleted; sanitization is not established
D. The encryption keys never had copies

## Question 3

A sanitization result lists a different asset identifier from the laptop being released. What is the best next action?

A. Resolve the mismatch before relying on that result
B. Release the laptop because the tool reported success
C. Change the asset tag to match without investigation
D. Delete the result record

## Question 4

Which information most directly helps determine whether a vulnerability report applies to an asset?

A. Its wallpaper color
B. The number of unrelated records in the inventory
C. The length of its hostname
D. Its installed product version and relevant configuration

## Explained answers

<details>
<summary>Open after answering</summary>

### 1: B

B establishes the responsibility and requirements needed for a decision. A assumes authority, C loses tracking before resolution, and D confuses physical location with approval.

### 2: C

C limits the conclusion to the observed action. A, B, and D need separate evidence.

### 3: A

A checks whether the evidence belongs to the target. B ignores identity, C alters the reference without reconciliation, and D removes useful evidence.

### 4: D

D supports applicability checks. A and C are unrelated appearance or naming properties; B does not identify the affected installation.
