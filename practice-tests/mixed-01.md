# Mixed practice test 1

Fourteen original questions covering the material currently available here. This is a short practice set, not a full-length exam simulation, an official CompTIA test, or a readiness prediction. No vendor weighting or scaled score is applied. These questions are independent of Professor Messer's material.

Choose one answer per question. Write your choices before opening the [answer key](mixed-01-answers.md). Optional practice limit: 20 minutes, chosen for this exercise rather than to match exam timing.

## Question 1

A public study guide needs evidence of who signed it and whether signed content changed. Which mechanism best matches?

A. Encrypt the filename
B. Publish a plain hash without a trusted reference
C. Use a digital signature with a trusted verification key
D. Rename the document

## Question 2

Which statement correctly classifies AES and SHA-256?

A. Both are encryption algorithms
B. AES is symmetric encryption; SHA-256 is a hash function
C. AES is a signature scheme; SHA-256 is asymmetric encryption
D. Both require a public/private key pair

## Question 3

A user signs in successfully but cannot edit the answer guide. Which check determines the edit permission?

A. Authorization
B. Authentication
C. Hashing
D. File synchronization

## Question 4

A tutor becomes a learner. Learners should only read practice files. What is the best access change?

A. Keep all tutor grants indefinitely
B. Delete every learner's account
C. Use one shared administrator account
D. Remove tutor-only grants while retaining required learner access

## Question 5

Rules use first-match processing. Rule 1 permits any source to server TCP port 443; rule 2 denies guests to that server. What happens to a guest's new TCP port 443 request?

A. Rule 2 always wins
B. Rule 1 permits it
C. The rules cancel each other
D. The packet is encrypted automatically

## Question 6

Two VLANs have unrestricted routing between them. What would restrict the permitted cross-boundary services?

A. Changing the switch hostname
B. Changing desktop wallpaper
C. Appropriate enforced ACL or firewall rules
D. Renaming the VLANs

## Question 7

Several accounts have failed logins from one recorded source, followed by a success. What is supported by these records alone?

A. The pattern needs investigation; compromise is not proven
B. Every account is compromised
C. The same password was definitely used on every attempt
D. The successful session is certainly legitimate

## Question 8

Which item should not be recorded directly in an ordinary security event log?

A. Action name
B. Event time
C. Success or failure
D. Plaintext password

## Question 9

A setting differs from the approved baseline. What should happen before deciding how to correct it?

A. Assume an attacker caused it
B. Delete the baseline
C. Confirm the difference and review applicable approvals and exceptions
D. Silently edit the reference to match

## Question 10

An exception permits remote support only while logging is enabled. Logging is disabled. Which conclusion follows?

A. All conditions are met because an exception exists
B. The stated exception condition is not met
C. Logging can never be restored
D. Every other setting is approved too

## Question 11

An outage is at 14:00 and the newest usable data point is 12:30. The RPO is one hour. What is the result?

A. RPO is missed because the data point is 90 minutes old
B. RPO is met because backups were scheduled hourly
C. RPO depends only on restore speed
D. No comparison is possible

## Question 12

An outage begins at 14:00 and required service is restored and validated at 17:00. For this scenario, RTO is measured from the outage and is four hours. What is the result?

A. RTO is missed by one hour
B. The backup timestamp alone answers it
C. RTO is always the same as RPO
D. RTO is met with a three-hour recovery

## Question 13

An unexpected message demands a password through a link within ten minutes. What is the best next step?

A. Use the link before time runs out
B. Pause and verify through a known independent channel, then report as appropriate
C. Reply with part of the password
D. Trust the logo alone

## Question 14

A. It must be genuine
B. No reporting is needed
