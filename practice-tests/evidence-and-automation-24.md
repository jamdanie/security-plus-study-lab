# Evidence and automation 24

Four original questions. Partial SY0-701 5.5 (1–2) and 4.7 (3–4). This targeted set is not a weighted mock exam.

[Session route](../resources/evidence-session.md) · [Contents](../study/contents.md)

## 1. A policy requires logging on every host. What does the policy alone establish?

- A. Every host passed a current test.
- B. The intended requirement.
- C. No exceptions exist.
- D. All logs are trustworthy.

## 2. Last month's screenshot shows one host with logging enabled. Which conclusion fits?

- A. Every current host is compliant.
- B. The screenshot proves no future failures.
- C. It supports a limited observation about that host and period.
- D. Other hosts do not need review.

## 3. The job must stop before changes if any target is unapproved. Input includes production-c outside the lab scope. What should happen?

- A. Report the scope error without making changes.
- B. Silently change every device.
- C. Ignore scope because the job is automated.
- D. Mark completion when the job starts.

## 4. An approved job completes one of two targets and fails on the other. What should the record say?

- A. All changes succeeded.
- B. No work occurred.
- C. The failed target is automatically fixed.
- D. Partial completion with per-target results and follow-up.

<details>
<summary>Answers and explanations</summary>

1. **B.** B identifies the policy's role. A requires test evidence. C needs exception records. D requires separate evidence.

2. **C.** C respects scope and time. A and B overgeneralize. D discards the remaining assessment scope.

3. **A.** A follows the supplied rule. B and C bypass it. D mistakes initiation for completion.

4. **D.** D preserves actual results. A hides the failure. B hides completed work. C invents recovery.

</details>
