# Control selection practice set 7

Five original single-answer questions. Partial SY0-701 1.1 alignment. Classify the function stated, rather than guessing from a product name. This targeted set is not weighted like the full exam.

## Question 1

Software sends an alert about failed logins, but does not block them. Which pair best describes this component?

A. Technical and preventive
B. Operational and corrective
C. Technical and detective
D. Managerial and deterrent

## Question 2

A manager approves a rule requiring access authorization before accounts are issued. Which pair best fits the rule itself?

A. Managerial and directive
B. Technical and corrective
C. Physical and detective
D. Operational and compensating

## Question 3

A firewall rule denies an unapproved connection. Which purpose is most directly demonstrated?

A. Detective
B. Deterrent
C. Corrective
D. Preventive

## Question 4

A team cannot implement a required control and proposes an alternative. What is needed before treating it as compensating?

A. Evidence that it costs less
B. Assessment of comparable protection and applicable approval
C. A label saying temporary
D. A second copy of the exception request

## Question 5

An analyst reviews camera recordings to investigate an entry. Which function is emphasized?

A. Preventive because every camera blocks entry
B. Directive because recordings establish rules
C. Detective because recordings support identifying what happened
D. Compensating because all recording is a substitute

## Explained answers

<details>
<summary>Open after answering</summary>

### 1: C

Software implements it, and it identifies activity. A incorrectly adds blocking; B and D misclassify both the mechanism or stated purpose.

### 2: A

The rule establishes direction through management oversight. B describes neither its implementation nor purpose; C describes a different mechanism; D assumes an alternative control not stated.

### 3: D

It blocks the unwanted action. Logging could be detective, a warning could deter, and remediation could correct; those functions are not what the prompt describes.

### 4: B

B evaluates whether the alternative satisfies the protection requirement. Cost, duration labels, and duplicate paperwork do not establish comparable protection.

### 5: C

The stated use is investigation. A invents blocking, B confuses evidence with direction, and D assumes a substitute requirement absent from the scenario.

</details>
