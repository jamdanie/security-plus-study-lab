# Exercise directory

Pick the skill you want to practice. Offline exercises use fictional scenarios; they do not require a live target or paid account. The local command exercises list their own requirements.

| [04. Firewall rule review](04-firewall-rule-review/README.md) | Offline | Trace first-match decisions |

## Before opening the answer

Write down the requirement, your decision, and the evidence that supports it. Compare with the worked answer afterward. If your answer differs, identify whether the gap was a concept, calculation, scope assumption, or missing verification.

The optional [PowerShell event sample](../concepts/powershell-log-review.md) is a separate local read-only exercise. No Windows execution result is claimed for the project owner.
