# Exercise 9: decide how to handle the request

Status: ready to try. This fictional offline scenario contains no live links or attachments.

## Message

Display name: Study Support

Subject: Final notice: account removal

"Your study account will be removed in ten minutes. Use the verification link in this message and enter your account password to retain access. Do not contact the regular support team because this is a special review."

## Your task

Identify the pressure tactics, choose how to verify the request, and explain what you would report. Does the message's polished wording resolve the concern?

<details>
<summary>Suggested answer</summary>

The short deadline creates urgency. The password request seeks a credential. The instruction to avoid regular support discourages independent verification.

Do not use the message's link or reply with credentials. Use a known service route and trusted support contact to check the request. Report the message through the approved process. Polished wording does not establish legitimacy.

The text is designed as a suspicious training example. In a real investigation, preserve and assess relevant evidence without opening attachments or following untrusted links.

</details>
