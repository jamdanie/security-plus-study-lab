# Visual study session: restore and hand off

[Game comparison](steam-data-center-games.md) · [All missions](hands-on-missions.md)

Use this session to practice decisions around a simulated outage. No game purchase is required.

1. Draw the dependencies in [recovery priority](../labs/39-recovery-priority/README.md).
2. Schedule the fictional tasks with one team, then two.
3. Write the [evidence handoff](../labs/40-evidence-handoff/README.md).
4. Attempt [four review questions](../practice-tests/recovery-and-handoff-22.md) before opening their key.

## If you use a game

Choose a supported repair or failure scenario in a copy of a project you control. Record the equipment, dependency, action, and actual outcome. A game's repair time is an observation about that product, not proof of a real service's recovery time objective.

When the game lacks business priorities or incident records, use the supplied offline conditions. Do not invent game features to complete the activity.

## What to keep

Save one schedule and one short handoff. Label assumptions and unresolved questions. Check whether someone else can explain your next action from the evidence you wrote down.

The activities support selected SY0-701 3.4, 5.2, 4.8, and 4.9 concepts. They are original learning exercises, not official performance-based questions or a readiness prediction.
