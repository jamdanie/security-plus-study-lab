# Bring an existing deck into the study project

The repository's public cards are original practice questions. Existing class decks can still help identify topics to cover, unclear explanations, and missing exercises.

## Export a deck for review

In Anki desktop, open File > Export. Select the relevant deck instead of the entire collection.

- Choose Notes in Plain Text for a readable export of fields.
- Choose an Anki Deck Package (.apkg) when the note types and media are needed too.
- If sharing a package for content review, leave scheduling information out when that option is available.

Review the export before sharing it. Remove personal notes or unrelated material. Menu labels can vary by version.

## Decide what belongs in the public repository

For each set, identify whether the question was written by you, copied from a textbook or class quiz, or obtained from another author. Check any permission or license before publishing someone else's material. Owning the book or adding a citation does not by itself authorize redistribution.

Keep copied textbook and class questions in your personal study collection unless sharing permission is established. We can use their topic coverage to write new scenarios and explanations without reproducing the original wording or answer choices.

## What the review will check

- Full question and choices on the front.
- A reasoning cue that does not give away the answer.
- The correct answer and explanation of each alternative on the back.
- Acronyms expanded and distinctions explained.
- Tags that identify topic and source status.
- Corrections supported by a source, with uncertain answers flagged for review.

Do not mark cards as reviewed or exercises as completed before that work happens.
