## How a section works

Read the explanation, predict the worked example, and answer its hidden-answer check. Follow the section's exercise or question link. For an error or correct guess, explain why the nearest alternative does not meet the requirement.

The [study index](study/README.md) now brings all eighteen main guides and seventeen practice sets into one place. Short pages add authentication factors, password storage, federation, certificate trust, data states, web attacks, mobile deployment, and local PowerShell event review.

## Status and scope

The objective reference is SY0-701 version 5.0; confirm your exam registration uses that code. Coverage is partial. The existing short question sets are not full weighted mock exams, and their scores do not establish readiness.

Exercises remain ready to try unless a learner records actual results. A performance-style task here is an original offline exercise, not a reproduction of CompTIA's interface. The website, hosted services, and automated GitHub workflow are not implemented.

## Textbook and sources

I'm using Mark Ciampa's *CompTIA Security+ Guide to Network Security Fundamentals*, eighth edition, published by Cengage, as a starting point. Supporting documentation is linked in the guides and [references](resources/README.md).

The textbook PDF and copied textbook review questions aren't included. Public practice questions are original supporting material. This project is independent and isn't affiliated with or endorsed by CompTIA or Cengage.
